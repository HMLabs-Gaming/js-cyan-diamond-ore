# JS Cyan Diamond Ore

[![Modrinth](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/modrinth_vector.svg)](https://modrinth.com/project/AkG5WZnx)
[![GitHub](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/github_vector.svg)](https://github.com/HMLabs-Gaming/js-cyan-diamond-ore)

A simple texture pack that turns the normal and deepslate diamond ore Block completely cyan. No other changes made. Perfect for much better visibility and compatible with all Minecraft versions.

Recommended for players with red-green colorblindness (Protanopia & Deuteranopia) for maximum visibility and contrast.
